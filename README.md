# CCNA Notes

This repository contains my notes, learnings, and resources while preparing for the **Cisco CCNA (200-301)** certification.

The goal is to build a strong foundation in computer networking, understand networking concepts in depth, and develop practical knowledge of Cisco networking technologies.

### Repository Contents

- **Networking Fundamentals** – Core networking concepts, devices, protocols, and architectures.
- **Network Access & IP Connectivity** – VLANs, switching, routing, and related technologies.
- **IP Services & Security** – Network services, security concepts, and configurations.
- **Automation & Programmability** – Fundamentals of network automation and APIs.
- **Cisco IOS Commands** – Important configuration and verification commands.
- **Troubleshooting** – Common networking issues and their solutions.
- **Data Center Networking Basics** – Introduction to data center architectures and technologies.
